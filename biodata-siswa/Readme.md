# Aplikasi Menampilkan Biodata Siswa

## Struktur Folder

```
biodata-siswa
 ┣ config               -> Berisi konstanta global (nama, versi dan author aplikasi)
 ┃ ┗ aplikasi.js
 ┣ data
 ┃ ┗ siswa.js           -> Berisi variable yang menampung data siswa
 ┣ logic                -> Berisi fungsi untuk menentukan keterangan lulus dan menampilkan data siswa
 ┃ ┣ logikaKategori.js
 ┃ ┗ tampilkanBiodata.js    
 ┣ app.js
 ┗ Readme.md
 ```

 ## Cara Menjalankan
 1. Buka terminal
 2. Jalankan perintah: node app.js
